# 🌦 Weather Forecast & Alert Application

A professional multi-page weather intelligence dashboard built using Python, Streamlit, WeatherAPI, Plotly, and Data Visualization techniques.

This application fetches real-time weather data, analyzes conditions, generates alerts, visualizes weather analytics, and exports reports.

---

# 🚀 Features

- 🌍 Real-Time Weather Forecast
- 🚨 Smart Weather Alert System
- 📊 Interactive Visual Analytics
- 📈 Temperature Trend Analysis
- 🌪 Wind & Humidity Monitoring
- 📁 CSV Report Generation
- 🌙 Modern Dark Dashboard UI
- 📌 Multi-Page Streamlit Application
- 📉 Gauge, Pie & Bar Charts
- ⚡ API Integration with WeatherAPI

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/weather-forecast-alert-application.git
```

## Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\\Scripts\\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

# 📦 Install Requirements

```bash
pip install -r requirements.txt
```

---

# 🔑 Setup API Key

Create `.env` file:

```env
WEATHER_API_KEY=your_api_key_here
```

Get free API key from:

https://www.weatherapi.com/

---

# ▶ Run Application

```bash
streamlit run Home.py
```
