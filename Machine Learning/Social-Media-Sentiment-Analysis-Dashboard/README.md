# 📊 Social Media Sentiment Intelligence Dashboard

An advanced ML-powered social listening and sentiment analysis dashboard. This project converts public opinion from social media comments, reviews, and feedback into actionable business intelligence using Machine Learning.

## 🚀 Features

- **🏠 Executive Home**: High-level overview of brand sentiment and key metrics.
- **✍️ Single Comment Analyzer**: Instant sentiment detection for individual text inputs.
- **📂 Bulk CSV Analyzer**: Upload datasets for batch processing and visualization.
- **📈 Premium Dashboard**: Deep dive into sentiment distribution, trends over time, and brand health.
- **🔍 Keyword Intelligence**: Automated extraction of trending words and customer emotions.
- **🚨 Complaint Monitor**: Real-time tracking of negative feedback with priority tagging.
- **📊 Campaign Analytics**: Platform-wise and campaign-wise performance comparison.

## 🧠 Tech Stack

- **Frontend**: Streamlit (Python)
- **Machine Learning**: Scikit-learn (Logistic Regression, TF-IDF Vectorization)
- **Data Processing**: Pandas, NumPy
- **Visualizations**: Plotly Express
- **Model Storage**: Joblib

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd SentimentAnalysis
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: .\venv\Scripts\activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application**:
   ```bash
   python main.py app
   ```

## 📂 Project Structure

- `app/`: Contains the Streamlit dashboard and custom CSS styling.
- `src/`: Core logic for preprocessing, training, and prediction.
- `models/`: Pre-trained sentiment model files.
- `main.py`: Entry point for training and running the app.
