# Job Application Tracker 🚀

A modern, beautiful, and feature-rich job application tracker built with React, Node.js, and modern web technologies. Track your job search journey with style!

## ✨ Features

- **Dashboard**: Beautiful overview of your job search stats and recent applications
- **Applications Management**: Full CRUD operations (Add, Edit, Delete job applications)
- **Advanced Analytics**: Detailed charts and insights about your application status, sources, and performance
- **Modern UI**: Professional, responsive design with animations and smooth transitions
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Interactive Elements**: Ripple effects, hover animations, and smooth transitions
- **Settings Panel**: Configure your preferences with a beautiful settings interface

## 🛠️ Tech Stack

### Frontend
- **React 19** - Latest React version
- **Vite** - Lightning-fast build tool
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Powerful animation library
- **Lucide React** - Beautiful icon library
- **Recharts** - Composable charting library
- **React Router** - Declarative routing

### Backend
- **Node.js** - JavaScript runtime
- **Express** - Web framework for Node.js
- **MongoDB/Mongoose** (coming soon) - Database and ODM

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd Job-Application-Tracker
   ```

2. **Install dependencies for client**
   ```bash
   cd client
   npm install
   ```

3. **Install dependencies for server**
   ```bash
   cd ../server
   npm install
   ```

### Running the App

1. **Start the client development server**
   ```bash
   cd client
   npm run dev
   ```
   The client will be available at `http://localhost:5174` (or another port if 5173 is in use)

2. **Start the backend server** (in a new terminal)
   ```bash
   cd server
   npm start
   ```
   The server will be available at `http://localhost:5000` (or your configured port)
