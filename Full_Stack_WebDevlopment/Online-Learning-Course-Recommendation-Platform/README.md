# 🎓 Online Learning & Course Recommendation Platform

A modern Full Stack EdTech platform where learners can discover courses, receive personalized recommendations, track progress, analyze learning performance, and manage enrolled courses through an interactive dashboard.

---

## 🚀 Features

### Authentication

* User Registration
* User Login
* Protected Dashboard
* JWT Authentication Ready

### Learning Dashboard

* Learning Statistics
* Course Progress Overview
* Recent Activity Tracking
* Personalized Learning Insights

### Course Management

* Browse Courses
* View Course Details
* Course Categories
* Course Difficulty Levels
* Instructor Information

### Course Recommendations

* Based On Skills
* Trending Courses
* Skill Gap Analysis
* Personalized Learning Suggestions

### Learning Analytics

* Weekly Learning Activity
* Course Completion Statistics
* Skill Proficiency Tracking
* Performance Reports
* Learning Insights

### Enrolled Courses

* Continue Learning
* Progress Tracking
* Lesson Completion
* Learning Achievements

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/online-learning-course-platform.git

cd online-learning-course-platform
```

### Frontend Setup

```bash
cd client

npm install

npm run dev
```

### Backend Setup

```bash
cd server

npm install

npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000

MONGO_URI=mongodb://127.0.0.1:27017/learning_platform

JWT_SECRET=your_secret_key
```
