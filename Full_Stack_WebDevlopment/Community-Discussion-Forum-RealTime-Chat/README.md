# Community Discussion Forum with Real-Time Chat

A modern full-stack community platform that combines discussion forums and real-time communication. Users can create discussions, participate in conversations, receive notifications, and interact through a responsive community dashboard.

## Features

### Authentication

* User Registration
* User Login
* Protected Routes

### Community Forum

* Create Discussions
* Browse Discussions
* Discussion Details
* Community Dashboard

### Real-Time Communication

* Real-Time Chat Interface
* Notification System
* Online Community Experience

### Dashboard Analytics

* Community Statistics
* Growth Analytics
* Engagement Metrics
* Trending Discussions
* User Activity Tracking

### User Management

* User Profiles
* Community Reputation
* Activity Monitoring
